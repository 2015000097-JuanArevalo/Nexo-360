Instalación

Android

  1. Descarga NEXO-360-Android.apk.
  2. Permite la instalación desde esta fuente cuando Android lo solicite.
  3. Abre el APK y pulsa Instalar.
  4. Inicia sesión con una cuenta creada por el personal técnico.

Windows

  1. Descarga NEXO-360-Windows.zip.
  2. Extrae la carpeta completa.
  3. Ejecuta nexo_360.exe; no muevas únicamente el .exe porque necesita las DLL incluidas.

La sección Movimiento Juventud conserva su ambientación propia dentro de la paleta visual NEXO 360.
